# 設計

このサーバは、LLMが指定したユーザー操作をCalDAVへ伝えるための境界です。データの正本はRadicaleにあり、MCPサーバが終了しても復旧すべき独自の永続状態はありません。

## 機能単位の構成

- `accounts.py` は接続設定とアカウントの識別を扱います。
- `calendars/` はカレンダーの型、検出、属性とコレクションの操作を扱います。
- `items/` は予定・タスク・日誌の型、iCalendar編集、CalDAV上のリソース操作を扱います。
- `sharing.py` はRadicaleのユーザー間共有APIを扱います。
- `availability.py` はfree-busy REPORTと空き区間の計算を扱います。
- `temporal.py` は日付・日時の意味を表現します。
- `dav.py` は認証、HTTP、XML、送信先の制約と通信エラーを扱います。
- `application.py` は複数アカウントの結果統合とユースケースを組み立てます。
- `server.py` は公式MCP SDKを使い、入力スキーマとツールを公開します。

`items/domain.py` の編集処理はHTTPやMCPに依存しません。ネットワーク側がその編集処理を呼び出します。入力モデルはPydanticで検証され、未知の引数は拒否されます。外部ライブラリのiCalendar表現は、編集対象外の情報を保持するためにも利用します。

## 更新の状態と競合

取得結果は `RetrievedItem` として、保存先、強いETag、解析済みの文書をまとめます。編集すると `EditedItem` を生成します。保存処理は `EditedItem` を受け取り、`If-Match` を使って書き込みます。

MCPから渡されたETagは、編集前の再取得結果とも照合します。再取得からPUTまでの競合は `If-Match` が検出します。作成はUIDから決定したURLと `If-None-Match: *` を使います。同じUIDによる再試行で別のコピーを作らないためです。

HTTP書き込みの成功と、その後のGET成功は別の状態です。GETだけに失敗した場合は `readback_failed` に `write_succeeded=true` と対象を含めます。書き込み中の通信断は `outcome_unknown` とし、自動再試行しません。

カレンダー属性や共有権限のAPIには、項目更新と同じETag保証はありません。これらについて複数操作の原子性や自動ロールバックを約束しません。

## 日時・繰り返し

日付、floating datetime、UTC、IANAタイムゾーン付き日時を別の型にします。夏時間で不存在・曖昧になるローカル開始時刻は入力境界で拒否します。繰り返し規則の解析と個別回の生成は既存ライブラリに任せます。

保存する文書には参照するタイムゾーン定義を補います。既存のVTIMEZONEは保持し、新しく追加する項目の定義は開始年の前年から終了年の100年後まで、カレンダー属性の定義は1900〜2100年を生成します。この範囲外の長期運用や将来のタイムゾーン法改正は、定義の再生成を必要とする場合があります。

個別回の編集は元のRECURRENCE-IDを保持した例外コンポーネントを作ります。個別回の削除はEXDATEで表現します。シリーズ編集は基本コンポーネントへの変更であり、独立した例外を一括上書きしません。

## 共有と相互運用

Radicaleの共有は標準CalDAVの予定操作とは別のアダプターです。利用者単位のmap共有に限定し、受け入れ・所有者権限・受取人の表示状態をサーバ側APIで管理します。接続先がAPIを提供しない場合は `unsupported` として返します。

共有先のRadicaleは、項目の作成・更新・削除について `DAV:write-content` を広告します。利用可能な権限を事前に確認し、実際のHTTP操作でもサーバの判定に従います。free-busy照会は詳細の読み取り権限を要求せず、REPORTを直接実行します。

## 検証

単体試験は、日時の意味、未知のプロパティの保持、個別例外、入力制約、HTTP境界を対象にします。結合試験は一時的なRadicaleを2ユーザーで起動し、共有の状態遷移、読み書き、競合、タイムゾーン、繰り返し、空き時間を検証します。stdio試験は公式MCPクライアントからプロセスを起動して実行します。

主な参照仕様は [RFC 4791](https://www.rfc-editor.org/rfc/rfc4791.html)、[RFC 5545](https://www.rfc-editor.org/rfc/rfc5545.html)、[Radicaleの共有設定](https://radicale.org/v3.html#sharing) です。
